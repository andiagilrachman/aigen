# Skeleton Project AIGen

Ekstrak isi zip ini ke:
- aigen-backend/  -> C:\xampp\htdocs\aigen-backend\
- aigen-frontend/ -> di mana saja, lalu jalankan `npm install` dan `npm run dev`

Backend sudah berisi:
- Koneksi database (config/database.php) - sesuaikan jika password MySQL Anda berbeda
- Helper Response, Settings, FeatureFlag, Auth, CreditManager
- Endpoint contoh: register, login, logout, me, theme presets, coming soon (list/vote/subscribe), credits balance, admin settings

Frontend sudah berisi:
- Fetch client wrapper (src/api/client.ts)
- AuthContext & ThemeContext siap pakai

Langkah lanjutan ada di blueprint-saas-saham-fase1.md, bab 11 (Roadmap).
